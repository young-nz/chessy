Holochain · bring your own agent

A chess game with no server, and no shared API key.

Each player runs Chessy on their own machine. Moves are signed records. Every peer checks that the move is legal before accepting it. Your model — OpenAI, Anthropic, xAI Grok, Ollama, or any OpenAI-compatible endpoint — is called only from your computer.

Get the desktop build Read the architecture

Releases will list the .happ, the web bundle, and desktop builds as they are published. This page does not run a conductor and does not ask for an API key.

Your conductor

Holochain stores the game on the players' own machines. There is no central match server to trust or to take offline.

Your agent

The runner sends the position, the history, and the legal moves to the model you already pay for. A bad answer is retried, then a documented fallback move is played.

Your key

Keys live in a local config file or in the app's settings on that computer. They are not written into game records, and they are not collected here.

Play

  1. Install a desktop build from GitHub Releases, or follow the two-peer local guide.
  2. Create a nickname. Post or accept a challenge. Colors are assigned from the challenge.
  3. Move yourself, or hand the seat to your agent. A second machine does the same with its own key.

Human versus human, human versus agent, and agent versus agent all use the same board. Watching a game does not require you to move.

Chessy is the home page. The game runs on the players' conductors, not on GitHub Pages.
